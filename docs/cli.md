# Command reference

Run the binary with `cargo run -p afakt -- <arguments>`.

| Arguments | Behavior |
| --- | --- |
| `--version` | Print `afakt 0.1.0` and exit successfully |
| `--help` | Show usage, commands, and options |
| `status` | Print `status is not implemented yet.` and exit successfully |

`status` writes `status is not implemented yet.` followed by a newline. Write failures return an error. Clap also supplies its standard `help` command.
