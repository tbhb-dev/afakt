# afakt

`afakt` is a proof of concept command-line tool written in Go. It has two commands: `status` prints a placeholder line, and `server` runs an HTTP API with health endpoints. Run it with `go run ./cmd/afakt status`, or build `bin/afakt` with `mise run build`. See [docs/components.md](docs/components.md) for the parts of afakt.

The repository also has shared development tools and docs. See [AGENTS.md](AGENTS.md) for repository guidance and [docs/index.md](docs/index.md) for the docs index.
